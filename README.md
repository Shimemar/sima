# sima

このリポジトリは、SiMa / Modalix 関連の実験、検証、デモ、PCIe/DevKit 周りの開発成果物をまとめたワークスペースです。  
主に、DevKit 向けアプリケーション、PCIe Host 向け検証コード、環境ごとの動作メモを格納しています。

## 主要なフォルダ

### 1. Devkit_0.4.0
DevKit で動かすためのサンプルアプリケーションや検証用コードが含まれています。

- `high-density-multi-stream-object-detector`
  - 高密度マルチストリーム物体検出のサンプルと設定。
  - C++ / Python の実行コードとモデル用設定ファイルが含まれる。
- `multimodal-assistant_e5`
  - マルチモーダル AI アシスタント関連の実装。
  - UI、サーバー、API テスト、証明書類などが含まれる。
- `taste_in_clothes`
  - ファッション判定/画像処理アプリケーションの実験コード。
  - GUI、サーバー、画像認識の Python スクリプトが含まれる。
- `oled`
  - OLED 関連の簡易テスト・制御コード。
- `Readme.txt`
  - DevKit / HOSTPC の起動手順やデモ実行コマンドが記載されたメモ。

### 2. PCIe_HHHL
PCIe ホスト向けの検証環境・アプリケーション群です。

- `llm`
  - LLM 周りのサーバー、TTS、テスト、静的ページ等が含まれる。
  - 音声応答・ブラウザ確認・テスト結果のログやファイルがある。
- `pcie-high-density-multi-stream-object-detector`
  - PCIe による高密度マルチストリーム検出のホストアプリ本体。
  - C++ 実装、設定 YAML、テスト、実行スクリプトが含まれる。
- 実行ログやテスト結果（`test-results`, `*.log`）
  - 各種検証の状態や確認結果を残すためのファイル群。

### 3. README_PCIe.md
PCIe 関連の作業記録ドキュメントです。

- インストール状況
- PCIe デバイス確認
- モデル取得
- チュートリアル実行
- 物体検出アプリの検証状況
- 次の作業項目

を整理して記録している。

## このリポジトリの用途

- DevKit 向けのサンプルやデモ実行コードの保存
- PCIe Host の検証・接続確認・推論実行の記録
- 実験ノートや動作手順の残し場
- 画像認識、音声、LLM、マルチモーダル処理のコード管理

## 参考情報

- `README_PCIe.md` は PCIe/ホスト側の詳細な作業記録。
- `Devkit_0.4.0/Readme.txt` は DevKit/HOSTPC の起動・実行手順メモ。
- 各サブフォルダには、アプリ固有の README や設定ファイルが存在する。

## 補足

このリポジトリは実験用・検証用のワークスペースとして管理されており、実行環境やモデルパス、ホスト情報がファイル内に記載されていることがあるため、必要な情報だけを参照して利用することを推奨する。
