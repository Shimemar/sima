# SRD: Webカメラ深度推定によるソナー風表示システム

## 1. 概要

Modalix DevKitに接続したUSB Webカメラの入力画像から単眼深度推定を行い、その結果を潜水艦のソナー（PPI表示）風に可視化するシステムを構築する。

### 1.1 目的

- Modalix MLA上での単眼深度推定の動作検証
- 深度情報を直感的に伝えるデモ表示（ソナー風UI）の実現

### 1.2 基本コンセプト

深度マップをそのまま表示するのではなく、画像の各列を方位角、各列の最近距離をレンジとして扱い、扇形の上面図（PPI: Plan Position Indicator）に変換して表示する。

## 2. システム構成

| 区分 | 内容 |
|---|---|
| ハードウェア | SiMa.ai Modalix DevKit、USB Webカメラ |
| 入力 | `v4l2src`（GStreamer）またはOpenCVによるカメラ取り込み |
| 推論 | 深度推定モデルをPaletteでコンパイルし、MLA上で実行 |
| 後処理・描画 | A65 CPU上でnumpy / OpenCVにより処理 |
| 出力 | HDMI直接出力、またはMJPEG / RTSPによるブラウザ配信 |

### 2.1 処理フロー

```
USBカメラ → 前処理 → 深度推定（MLA） → 列ごとの最近距離抽出 → 極座標変換 → ソナー描画 → 出力
```

## 3. 機能要件

### 3.1 深度推定

- FR-01: カメラ入力1フレームごとに深度マップを出力すること
- FR-02: 推論はMLA上で実行すること

### 3.2 距離プロファイル抽出

- FR-03: 深度マップの中央付近の水平帯を対象に、各列の最近距離を抽出すること
- FR-04: フレーム間のちらつきを抑えるため、時間方向の平滑化（EMA等）を適用すること

### 3.3 極座標変換

- FR-05: 画像の列位置を方位角に変換すること（カメラの水平画角に対応、Webカメラで約60〜70°）
- FR-06: 深度値をソナー表示上のレンジ（中心からの距離）に変換すること

### 3.4 ソナー描画

- FR-07: 扇形のPPI表示とすること
- FR-08: 往復または回転するスイープ線を描画すること
- FR-09: エコー（検出点）に残光（フェードアウト）効果を付けること
- FR-10: 距離リングと距離ラベルを表示すること
- FR-11: 緑単色を基調としたソナー風の配色とすること

## 4. 非機能要件

- NFR-01: カメラ入力から表示までをDevKit単体で完結させること
- NFR-02: 後処理・描画はCPU負荷の軽い実装とすること
- NFR-03: FPSを計測し、デモとして違和感のないフレームレートを確保すること（目標値はStep 3で決定）

## 5. モデル候補

| モデル | 特徴 | 備考 |
|---|---|---|
| MiDaS v2.1 small | CNNベース。MLAでコンパイルしやすい | 第一候補 |
| Depth Anything V2 Small | 高精度。ViT系 | コンパイル可否と量子化後の精度を要確認。SiMa Model Zooの対応状況を事前に確認する |

## 6. 制約・注意事項

- 単眼深度推定の出力は基本的に相対深度である。MiDaSの出力は逆深度のため、距離表示には変換が必要。
- メートル単位で表示する場合は、既知距離の物体による簡易スケール校正、またはMetric版モデルの採用を検討する。ソナー「風」の演出であれば相対深度で可とする。
- 表示範囲はカメラの水平画角に依存し、360°表示にはならない。
- フレーム単体の深度推定はちらつきが出るため、時間方向の平滑化を必須とする。

## 7. 開発ステップ

各ステップの完了時に確認を行い、次のステップへ進む。

| Step | 内容 | 完了条件 |
|---|---|---|
| 1 | PCプロトタイプ: Python + ONNXでMiDaS smallを動作させ、ソナー描画ロジックを確立 | PC上でカメラ入力からソナー表示まで動作 |
| 2 | Paletteによるモデルの量子化・コンパイル、PC上での精度確認 | 量子化後の深度出力が許容範囲内 |
| 3 | DevKitへのデプロイ、カメラ入力から表示まで通し動作、FPS計測 | DevKit上でリアルタイム表示 |
| 4 | 演出追加: ピング音、ターゲットロック表示、距離アラート等 | デモとして完成 |
